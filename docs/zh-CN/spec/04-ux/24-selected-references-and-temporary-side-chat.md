# 选中文本引用与临时侧边聊天

> **翻译说明：** 本页是与 [英文源规格](/spec/04-ux/24-selected-references-and-temporary-side-chat) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

状态：已在本地实现；发布验证另行记录。

## 用户流程

在本地桌面端的用户消息或助手回复正文中选中文字后，会出现**添加到对话**和**在侧边聊天中提问**。代码会保留换行，渲染后的数学公式使用其 TeX 源码。跨多个消息的选区按来源拆成多个引用。按钮、输入框、隐藏内容及已有引用控件不会被选入。按 Tab 可进入工具栏，按 Escape 可关闭。操作按钮采用紧凑的 ghost 样式，不包在带边框、圆角或凸起效果的容器中，与桌面端现有工具栏一致。

添加到对话会追加结构化引用，不会覆盖已输入文本或附件，也不会自动发送。无边框的引用数量控件可展开为带编号的摘录，并以细微的引用竖线标示。将鼠标悬停或聚焦到编号来源时，会显示完整的会话和消息标识；摘录本身不显示冗长标识。草稿中的引用使用带可访问移除标签的小型关闭按钮。主对话、侧聊和已发送引用共用此展示。普通发送、排队发送、即时引导、主聊和侧聊的消息编辑/重试，以及未回答时停止后的草稿恢复，都会保留引用。引用在已保存消息中仍是结构化数据；统一转换逻辑会先添加用户角色的引用材料，再添加问题。不会将引用提升为系统消息，也不使用 Codex 私有注释协议。

## 临时执行

每个主对话至多对应一个侧聊。再次选择文本会复用侧聊、追加引用、保留草稿并聚焦输入框。打开侧聊不会发送提示词。新侧聊继承解析后的模型、提供商、推理等级、模式、Fast/Ultra 选项及有效权限策略；其配置和后续上下文会独立演进。

侧聊通过独立会话标识使用现有 Agent 运行时、工具、审批、队列、停止控制与事件。侧聊使用主对话实际工作目录，包括隔离主对话的 worktree；不会再创建 worktree，也不会合并或回滚已完成的文件修改。

初始上下文按需从主对话当前有效运行时上下文构建，或从恢复后的规范转录记录、压缩检查点和已恢复附件构建，不会从界面可见行重建。已完成工具结果作为证据，不作为待执行任务。未完成工具调用和未提交的流式助手文本不会继承；用户选中的流式文本仍可作为明确引用发送。读取上下文失败时会显示错误并允许重试，不会悄悄改为空上下文启动侧聊。

继承的上下文只保存在侧聊运行时必需的内存中。子会话 JSONL 只记录侧聊新增内容。侧聊压缩只保存在内存中，不会把主对话历史摘要写入子会话检查点。改变子会话配置时会保留有效上下文、压缩内容及子消息标识，包括重建运行时之后。智能停止、编辑和重新生成会在内存中回退子会话轮次，不会丢弃该上下文。

## 布局与生命周期

侧聊是归属当前会话的 WorkPanel 标签。切换对话或标签、打开设置或收起面板只会隐藏它，不会丢弃内容。在窄窗口中，侧聊覆盖右侧区域，而不是挤压主对话；临时抽屉宽度不会写成用户首选面板宽度。为确保 Windows 标题栏旁的标签/关闭按钮可操作，侧聊渲染宽度最小为 360 px；旧的紧凑偏好和其他面板不受影响。

侧聊转录区和输入框使用主聊共享的表面、间距及单行响应式工具栏。输入框采用覆盖层：转录区只按测量高度为其预留一次空间，即使引用或多行草稿让输入框变高也如此。不得在输入框上方留下额外遮挡区域。窄面板会收紧模型/模式标签和账号额度控件，但不会让操作目标重叠；完整标签仍可通过工具提示和菜单查看。展开面板后，描述性标签会恢复到同一行。

当明确关闭标签时，如果有草稿、排队输入、运行任务、委派任务或未回答的交互，会先确认。确认后会取消工作、清空队列、等待运行时完成收尾、回收应用拥有的子转录/暂存文件并释放状态。项目文件不受影响。应用启动时会回收残留的临时子记录，然后才恢复普通历史和移动端会话；不会重放侧聊提示。关闭操作也会取消等待权限审批的工具，防止它们之后执行，并等待子委派任务结束。

后台命令栏归对应的 Composer 会话所有，不会同时在两侧显示。若侧聊还有分离运行的命令，关闭时也要确认。确认关闭侧聊会停止并回收其后台命令；普通轮次取消则仍让分离命令继续运行。关闭侧聊不会停止主对话的后台命令。

Host schema 26 增加父子生命周期归属与排队引用元数据。既有转录不会被重写。临时会话不进入普通历史、全局搜索、移动端同步或可复用的主会话选择。删除父会话前必须先关闭子会话。

## 范围

此功能面向 Host 管理的本地桌面对话，不包括原生 Pi 或远程会话协议适配器。侧聊具备 Agent 执行能力，但不是第二个持久历史编辑器：分支/修订操作及应用级插件 Composer/语音分派仍只在主对话提供。侧聊编辑和重新生成只回退子会话自己的轮次，不丢弃继承上下文，也不创建持久的替代版本。会话模式、压缩和可信扩展斜杠命令会明确作用于侧聊；应用级命令会说明仅适用于主对话，不会切换目标。普通侧聊问题、附件、工具、审批、队列和模型/模式控制使用现有按会话隔离的路径。无服务端变更或版本升级。
