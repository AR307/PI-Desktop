# Ultra 协作

> 对照[英文源规格](/spec/03-runtime/ultra-collaboration)。

Ultra 是会话执行策略，不是厂商推理枚举。桌面滑块最右端及手机模型面板提供该选择，Rust 沿既有设置保存，新会话关闭，普通推理选择保留。切换 Provider、模型或 MC 组会关闭 Ultra，除非同次提交明确再开启；Fast 与其独立。

## 执行

启动时分别解析每个模型明确支持的最高原生推理，无声明不猜测。用户和批准后的计划可开启，标题等辅助与生图不继承。计划和 Goal 筹划仍限制执行，但可使用主模型最高推理。

复用 Task、TaskWait、TaskList、TaskStop 及现有容量。独立子任务明确分工，由主代理负责整合、验证和向用户提问，不设固定数量，不递归委派，不自动换模型，不另建调度器。运行中修改下一轮生效，空闲父代理重新绑定不改变已启动子代理的模型、组、推理和 Fast。

新子代理默认继承父绑定；显式模型覆盖须获子代理授权，用户固定定义的模型仍生效。内置推理默认不限制 Ultra。Task.thinkingLevel 或用户定义等级是显式选择，不支持时发送前拒绝；resume 省略保留子代理原等级和精确绑定。

## 分派与异步交接

Ultra 成功发起一批 Task 后正常结束父轮次。该批全部调用启动并写入工具结果后才经过 pi 的 finishTurn 边界。输入区恢复可用，子卡仍运行；不再请求父模型或轮询 TaskWait 维持后台任务。普通模式保留原继续策略。

报告经内部队列唤醒父代理整合，并发布可见 ReturnToParent 回执。即使子任务早于 Task 返回完成，也在父结束事件后排入现有队列，不偷偷延长分派轮次。已就绪报告共用唤醒，后来报告按原边界继续。父代理可整合部分结果后再结束等待，不要求全部同时完成，也不阻止用户发新消息。边界处接受的用户消息仍正常进入 steering 续答，不被扣留。

整批拒绝不伪称成功交接，父代理可解释错误，但不能静默换模型或接管用户明确委派的工作。错误、截断、停止语义不变；父停止与子取消独立。

## 持久化与界面

ultra 随配置及 current、next、chat 快照传输，独立于 SessionThinkingLevel。Task 摘要保存实际模型键、组、原生推理、Fast 和完成状态。完成只更新原 Task 行，不重执行或重复算 usage；旧快照不能复活已完成子代理。两端展示实际子配置，不可用工具或定义在启动前报错，不显示虚假协作。

MC 仅转发已有帧，无新接口和表。受控 Electron/手机验收证明接线、并发、下一轮隔离和续跑，不证明真实模型拆解能力；真实付费验收另行授权。

## 当前档位摘要

只有选中 Ultra 才显示所选绑定最高原生等级加 Workflow + Subagent，例如 Max + Workflow + Subagent 或 Xhigh + Workflow + Subagent，不按系列名猜测。无原生推理只显示 Workflow + Subagent。退出 Ultra 或换模型隐藏摘要，取代此前常驻费用提示，不改变执行。

## 子代理控制与模型身份

报告是内部通知，不是虚构用户消息；父代理可静默消费，正常助手回答及子卡仍可见。父停止不停止独立子代理，也不把其卡片误标为已停止。桌面提供逐个及全部停止，以真实任务结束为准。

Task.model 选择明确 Provider ID/model ID。获授权账号模型的各 text 分组分别列出，普通服务商同名模型也区分来源。歧义别名返回精确候选，不私选组。启动显示实际模型、渠道、组和推理。显式模型与 resume 不使用定义的备用模型；resume 保留原子历史和授权绑定，渠道失效明确报错，不继承父模型。委派失败不授权自动替换或接管任务。
