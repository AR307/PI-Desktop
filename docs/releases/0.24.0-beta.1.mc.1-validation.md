## Limits

- GitHub CI dispatch returned HTTP 422: `Actions has been disabled for this
  repository`. The PR has no hosted checks/statuses; main has no protection
  requirement. Local candidate and equivalent integration-tree evidence is the
  available validation.
- The full Desktop suite is not all green on Windows: macOS signing and POSIX
  shell/SSH/socket cases require other platforms. Relevant corrected integration
  cases were rerun; platform restrictions were not weakened.
- The portable NSIS launcher does not forward the boot probe's stdout. Its
  actual GUI/chat path was verified separately. Installer wizard interaction,
  macOS/Linux builds and live paid-provider acceptance were not run.
- Windows artifacts are unsigned. Existing Pi/Codex clients, accounts and
  production services were not restarted or modified.
- An upgraded database is not a supported downgrade profile. Preserve the
  automatic pre-upgrade backup when evaluating this prerelease.
