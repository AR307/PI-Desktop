# PI Desktop 0.18.2 - Storage archive and link repair

## Changes

- Copy app.asar archives as physical files during storage migration, fixing Electron ENOTDIR failures.
- Preserve Windows file and directory links even when their targets no longer exist.
- Normalize trailing separators in Windows junction targets so recreated links do not falsely fail verification.
- Include source and destination paths in copy errors.

## Scope

Windows-only patch on published 0.18.1 (7815e00deac258ecdf67bc66e8cd11837e37a966), with storage repair a00577626e81fb1c48f54c1765a7d519b377d4db. Existing first-install migration and original-backup retention remain unchanged. Android remains at 0.18.0; no Android, macOS or Linux package is published. No production provider, installed user profile, or failed user migration destination is used for acceptance.

## Packages

Windows x64 NSIS installer, Portable EXE and Portable ZIP, with latest.yml and installer blockmap. Packages are built locally using the existing dependency environment. No new Windows Authenticode certificate is supplied. The release commit skips the inherited multi-platform workflow, matching the preceding Windows-only release.
