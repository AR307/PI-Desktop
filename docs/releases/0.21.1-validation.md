# PI-Desktop 0.21.1 release validation

## Included changes

- Preserve the MirrorCoding relay binding when projecting Gemini provider
  headers at session launch, and recognize Google's native API-key header as
  a local relay-binding carrier. The temporary binding is not forwarded as an
  upstream credential or used to bypass authentication.
- Map Ultra to the supported `xhigh` reasoning level on upstream model
  requests while retaining subagent spawning. Explicit worker `max` remains
  unchanged; persisted provider metadata is not rewritten.
- Bump app, package, and Rust workspace versions to 0.21.1; refresh the
  bundled models.dev catalog and add matching localized release notes.

## Validation completed

- Shared package typecheck passed; changelog and Ultra tests passed
  (10 tests).
- Agent runtime typecheck passed; provider binding, Ultra policy, runtime
  Responses SSE, and subagent tests passed (17 tests; 411 unrelated runtime
  cases skipped by the targeted name filter).
- MirrorCoding Gemini session, relay key, and catalog tests passed (17 tests):
  the real Google SDK path preserved relay binding, invalidated bindings were
  rejected, and native API-key carriers stayed local.
- Native process journey passed: the Gemini Agent read a fixture file through
  Host and Sidecar, completed its tool continuation, then continued with a
  second user turn (local controlled relay only).
- Host release build passed with Rust 1.90.0 and `--locked`. The host build
  produced by the release candidate was included in the packaged application.
- Desktop typecheck and Electron production build passed. Vite reported large
  chunk-size advisory warnings; no build error occurred.
- Windows x64 NSIS installer, portable ZIP, and portable EXE were produced.
  The NSIS updater feed and blockmap were generated.
- Packaged Windows startup E2E passed on the isolated candidate: app version
  0.21.1, Host protocol 11, and 800 session records. The test used a new
  temporary data directory and retained its evidence; no installed/user
  profile, active Pi/Codex process, or user database was used.
- Release documentation/version preflight passed for 0.21.1.

## Remaining release validation and limits

- macOS arm64/x64 packages are pending the dedicated unsigned package
  workflow; Linux artifacts are not part of the prior published platform set.
- No live paid Gemini upstream request was made in this release validation.
  The local relay/SDK/Host/Sidecar flow validates the client-side binding,
  tool continuation, and next-turn context, but does not claim upstream
  provider availability.
- Active Pi and Codex instances were not restarted.
