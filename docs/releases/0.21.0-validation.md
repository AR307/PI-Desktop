## Integration decisions

The release retains completed selection references, temporary side chats,
daily check-in, subscription details, wallet controls, Claude cache duration,
Agent-generated image display and partial-stream recovery. Explicit Stop and
permanent errors remain non-retriable. Historical tools are not re-executed.

The upstream TaskDock replaces the old BackgroundTasksBar while retaining
session ownership. Upstream typed tool cancellation replaces the older shared
registry extension; side-chat close still cancels approvals and child commands.
Upstream tool-call identities and output caps compose with the fork's stream
watchdog and partial-response recovery. GenUI text keeps quote provenance.

Storage migration, browser viewport and transcript identity/UTF-8 maintenance
already exist in the maintained line or upstream. Older independently developed
outbox/RPC branches and their unfinished merge worktrees are not treated as this
conversation's accepted feature line and are left untouched. No private source
histories, account data or test profiles are committed.
