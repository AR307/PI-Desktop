# PI Android 0.20.4

## Scope

Android-only release from published 0.20.3 (`6f87cf3c8`). Workspace versions are
synchronized to 0.20.4. The Windows desktop stays at its published 0.20.2
packages; no desktop assets or update feed are published. The APK and its
`mobile-update.json` are published to `AR307/Mirrorcoding-APP`; the source
tag `v0.20.4` is in `AR307/PI-Desktop`.

## Changes since 0.20.3

- The native updater stored only a DownloadManager job id and reported any job
  that had once succeeded as downloaded. A phone that had downloaded and
  installed 0.20.2 was then offered "Install update" for 0.20.3. That button
  reopened the old 0.20.2 APK, and the newer release could not be downloaded.
  - A download now records the APK URL and versionCode it was started for.
  - The job and its file are discarded once that version or a later one is
    installed, when the offered update names another APK, and for records
    written before 0.20.4.
  - Starting a download replaces any earlier one. The installer opens only the
    APK downloaded for the offered update.
- The login screen shows the update section again before sign-in. The
  redesign had moved it into Me, which exists only after sign-in.
- Phones that still hold such a record from 0.20.3 or earlier need one manual
  installation of 0.20.4. 0.20.4 then clears the record when it starts.
