- Upstream: `b73b6dfae97ec4daacb4cea000b0a7bbba7ea27d` (2026-10-21).

  temporary side chats, storage fixes, and the fork's branding.

## Environment

Node 24.19.0, pnpm 12.8.1, Rust 1.90.0, Electron 43.6.0. Pi 1.3.0 requires a
new worktree-local dependency installation; the existing pnpm store and Rust
build caches are reused. No existing development environment is replaced.
The lockfile's conflicted Vite/esbuild edge was restored to upstream 0.28.1,
then checked with a frozen installation.

## Acceptance

Results are filled in from executed commands before publication. Targeted
Electron journeys use isolated profiles and controlled local HTTP endpoints;
no paid providers or running user profile are used. Image coverage includes
all three transcript display modes, preview/save/reference, reload/restart,
and the separately configured multi-image gallery.

## Known platform limits

The fork has no Apple signing/notarization credentials. macOS packages are
unsigned and not notarized; automatic macOS installation and Gatekeeper
acceptance are not asserted. Windows publisher trust is also not asserted.
Native packaged boot checks do not cover interactive installer wizards.
