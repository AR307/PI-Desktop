# PI Desktop 0.18.1 - Storage migration repair

## Changes

- Change the storage location on first launch without pre-creating the selected folder or initializing the old data directory.
- Migrate existing data to a new folder or drive while retaining the original backup.
- Preserve Windows project path keys so project memory and instructions remain accessible after migration.

## Scope

This Windows-only patch starts from published 0.18.0 source fb3cec1af92c92ea7038c0275f1f0550d1d3d98e and applies the tested storage repair. Existing 0.18.0 functionality and mobile protocol behavior are retained. The paired Android application stays at 0.18.0; no new Android, macOS or Linux package is published. No production provider call or MC deployment is part of this update.

## Packages

Windows x64 NSIS installer, Portable EXE and Portable ZIP publish to AR307/PI-Desktop with latest.yml and the installer blockmap. Packages are built locally from the dedicated release branch; no new Windows Authenticode certificate is supplied. The release commit skips the inherited multi-platform tag workflow, as in the previous local Windows release.

## Validation

Release-candidate and packaged-payload checks passed before publication. Synthetic profiles are retained separately. The installed user application and real profile are not changed. Native folder-picker results and relaunch dispatch are scripted in the focused Settings migration harness; subsequent startup phases are separate real Electron processes. Full unrelated suites, installer-wizard acceptance and production-account behavior are not claimed.

- Eight storage filesystem regressions, five localized changelog tests and the Rust project-memory relocation regression passed.
- All nine workspace TypeScript builds, Desktop typecheck, agent sidecar bundle, Electron production build and optimized Rust Host build passed.

- NSIS, ZIP and Portable package payloads launched as 0.18.1 in isolated profiles, opened seeded history, served Settings IPC and passed the large-history rewrite/delta regression without renderer errors. Native screenshots were reviewed.
- Release version/document checks, agent-policy synchronization and diff checks passed.

Installed dependency links initially mixed patched and unpatched Pi packages. Release-local copies now use existing patched packages with consistent intra-package resolution; the shared package store was not modified. No fresh package installation was performed. The models catalog remains the pinned 0.18.0 snapshot for this storage-only patch; the older runbook claim that release.mjs refreshes it does not match the current script.

The NSIS installer wizard and Portable self-extractor were not executed; acceptance covers their generated executable payloads. Original Windows POSIX-mode and unrelated documentation/full-suite limitations remain documented in the storage fix and 0.18.0 release notes. No all-green full-suite claim is made.
