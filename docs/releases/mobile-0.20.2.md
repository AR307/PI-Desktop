# PI Mobile 0.20.2

- New shared desktop/mobile logo and Android launcher icon.
- Sessions, Activity and Me navigation, account settings and reading-position
  improvements from the mobile redesign.
- Background connection and notification controls for desktop task attention.
- Compatible with PI Desktop 0.20.2, including account-authorized agent image
  generation without manually selecting an image model.

The phone remains a companion to an online desktop. Execution, model
credentials, permissions and original conversation data remain desktop-owned.
