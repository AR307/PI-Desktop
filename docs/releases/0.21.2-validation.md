# PI-Desktop 0.21.2 release validation

## Candidate and scope

- Base: `2886d7be1e4fcc74b5cd32653ed9c9361d9bd423` (origin/main).
- Upstream: `4ad0094e87b3c9ab75653a770f67f0d09abd63a4`.
- Executable candidate: `8b693df483f48b1640c6a8b1f403105dfd904399`.
- Windows x64 release; other platforms are not part of this publication.
- Pi 1.5.0, custom/staged modes, Computer Use settings and upstream UI/runtime
  maintenance retain MirrorCoding accounts, Gemini bindings, Ultra-to-xhigh,
  independent side chats and mobile synchronization.
- Schema 30 converges fork/upstream storage. The schema-26 upgrade regression
  preserves conversation messages, queued prompts and mobile revision records.

## Completed validation

- `pnpm build:js`, Desktop production build/typecheck/lint, architecture,
  agent-policy, Pi dependency/patch and release-documentation checks passed.
- `cargo fmt --all -- --check`, Host Clippy and release build passed.
  Host tests: 1,287 passed, one ignored. Runtime: 1,998 passed, one skipped.
- Shared, i18n, plugin SDK/DevKit, voice, Computer Use, agent-host, RACP,
  mobile and documentation package tests passed. Three Host-runtime filesystem
  cases that timed out during parallel builds passed when rerun alone with
  one worker and a 30-second test deadline.
- Targeted Desktop regressions passed, including 44 history/Smart Stop cases
  and 35 model/thinking contract cases. Broad-suite integration failures were
  corrected and rerun; platform limits below remain explicit.
- Real isolated Electron user paths passed for model selection, custom/staged
  modes, Computer Use permissions, Jev settings, deep file search, agent
  mentions, S3 settings, lifecycle dialogs and optional provider credentials.
- `e2e-mode-definitions.mjs` passed through Host/process approval, command gate,
  stage completion and return to Agent.
- `e2e-composer-model-selection.mjs` passed: source rail/search, target-model
  default thinking, same-model manual override and one label per reasoning stop.
  The duplicate-label regression failed before the integration correction.
- `e2e-selection-side-chat.mjs` passed: quotes, inherited context, actual tools
  and approvals, child-only model/thinking selection through the native range,
  Smart Stop/resend without discarded-text replay, edit after mode rebuild,
  settings navigation, dark/light narrow layouts, queued work, background and
  delegate cancellation, and restart cleanup. Screenshots were inspected.
- Development and final packaged startup probes passed at 0.21.2 with Host
  protocol 11 and 800 fixture sessions. Final packages were rebuilt after the
  reasoning-label and Smart Stop corrections: NSIS installer, portable EXE,
  portable ZIP, installer blockmap and `latest.yml`.
- The final packaged probe covered eight complete list refreshes, consistent
  capabilities, sandboxed preload IPC and disabled Ctrl-R reload. Screenshots
  and test state were isolated from installed profiles.
- PR integration ref `fd0e4ad47bc01660d34b39be27d728a7fecfc739` had the same
  Git tree as the executable candidate. Later validation-document commits do
  not change the executable source.

## Limits

- GitHub workflow dispatch returned HTTP 422, `Actions has been disabled for
  this repository`, despite the repository permissions API reporting enabled.
  PR #6 has no hosted check runs/status contexts; main has no protection gate.
  Local validation is the available release evidence.
- The full Desktop suite is not entirely green on Windows. macOS signing and
  POSIX shell/SSH/socket fixtures require another platform; no production
  behavior was weakened to make those fixtures pass.
- macOS/Linux packaging and live Computer Use/model-provider acceptance were
  not run. Local HTTP fixtures replace only provider endpoints. No paid model
  request, production service or real user profile was used. Active Pi/Codex
  instances were not restarted.
- Lint passed with four broken-link warnings in test-created scratch folders.
- Database upgrade tests do not authorize downgrading an upgraded profile to
  an older application; keep the automatic pre-upgrade backup for rollback.
