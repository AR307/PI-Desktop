# PI Desktop and Android 0.15.11

## Release scope

- Desktop: AR307/PI-Desktop; Windows x64 installer, portable EXE and ZIP.
- Android: AR307/Mirrorcoding-APP; application source remains in this monorepo.
- Candidate includes all committed work through 9cb89de6e8df1c7f73285c8b08a8154b839e122f, based on origin/main 920b12b8e053165d343a421b3cb8ee93c50a436a.
- No changes from unrelated dirty worktrees are included.

## Changes

MirrorCoding catalog-driven routing, session Fast, native model management,
response classification/continuation, Android session controls and images,
Ultra model-specific reasoning and asynchronous handoff, exact cross-model
subagent bindings, independent stop/resume controls, native clipboard access,
and durable expandable ReturnToParent results.

## Packaging

Workspace/app version: 0.15.11. Android applicationId:
xyz.mirrorcoding.pi.mobile, versionCode: 3. The release-variant APK retains the
signing identity of the existing 0.15.1 distribution for in-place upgrades.
That identity is the existing Android debug certificate, not a new production
signing certificate; the APK itself is not debuggable. Keys are never shipped.
Windows packages have no newly supplied Authenticode certificate.
No macOS or Linux binaries are built in this Windows release task.

## Validation

Initial pnpm build:js, desktop typecheck, full configured lint, Rust 1.90.0
release build, Android assembleRelease and release documentation checks passed.
The installed default Rust 1.86.0 was too old for the existing lockfile; no
dependency downgrades were made. Sidecar was rebuilt before packaging.

Application suites passed for shared (1174), runtime (1216), host-runtime
(109 passed, 3 skipped), agent-host (60), mobile (18), i18n (37), plugin SDK
(374), plugin DevKit (49), RACP (21), and voice runtime (51).
The broad Windows run is not a green full-suite result: pi-host tests require
POSIX paths/permissions and a host test binary; desktop has platform-specific
macOS/shell/SSH/path fixtures and plugin-lab failures. These remain explicitly
separate from Windows/Android release acceptance.
Stale clipboard/disclosure/cancellation assertions and the Windows import-test
boundary were repaired; their targeted suites pass 59 tests. Missing domain
translations and ADR index drift are repaired; 87 locale pairs and 562
documentation pages validate.

Actual packaged and controlled Electron/Android acceptance is recorded below
before publication. No paid model or production MC request is required.
